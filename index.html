Install without SmartScreen blocking

  1. Download the signed zip (safer than a raw exe from the browser).
  2. Extract MobileStudioPro.exe.
  3. If Windows still warns, double-click MobileStudioPro.cer → Install Certificate → Current User → Place all certificates in Trusted Publishers.
  4. Right-click the exe → Properties → tick Unblock → OK, then run it.

This PC can also trust the publisher automatically with the local sign-and-trust script. Microsoft SmartScreen cloud reputation for new publishers still needs a paid Authenticode certificate (DigiCert / Azure Trusted Signing) before every other computer on the internet stops warning.
